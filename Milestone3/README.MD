# Milestone 3 – Secure Authentication, AI Engine & Enhanced User Experience
## Description
In this milestone, the application was significantly enhanced by integrating secure authentication, intelligent language processing, and advanced visualization features. The system now includes OTP-based authentication using JWT and Ngrok, along with AI-powered capabilities such as multi-language Q&A, multi-language summarization, and a knowledge graph for entity and relationship visualization.

Additionally, the application introduces a Readability Dashboard and several UI/UX improvements to provide users with a more intuitive and efficient experience.
## Features Implemented
- Secure Authentication
- Q&A Multi-Language Engine
- Multi-Language Summarization
- UI/UX Improvements
- System Integration
## How to Run
1. Install dependencies
2. Run Streamlit app
3. Use ngrok to expose the app
