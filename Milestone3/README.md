# Milestone 3 – Secure Authentication, AI Engine & Enhanced User Experience
## Description
In this milestone, the application was significantly enhanced by integrating secure authentication, intelligent language processing, and advanced visualization features. The system now includes OTP-based authentication using JWT and Ngrok. Additionally, AI-powered capabilities were integrated using several transformer-based models from Hugging Face and leading AI research organizations. These include the  for multilingual translation, DistilBART CNN and PEGASUS models for text summarization, and FLAN-T5 from Google Research for advanced natural language understanding and generation. For paraphrasing tasks, models such as T5 Paraphrase PAWS and BART Paraphrase were utilized. These models enable features like multi-language Q&A, multi-language summarization, and intelligent text paraphrasing. Furthermore, the application introduces a Knowledge Graph for entity and relationship visualization, a Readability Dashboard, and several UI/UX improvements to provide users with a more intuitive and efficient experience.
